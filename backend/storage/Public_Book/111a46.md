# Markdown Live Preview - Technical Documentation

## Overview

**Markdown Live Preview** is a full-stack web application for real-time markdown editing, previewing, and sharing. Built with React + Vite (frontend) and Express.js (backend).

## Tech Stack

| Layer | Technology | Purpose |
|-------|-----------|---------|
| Frontend | React 18 + Vite | SPA with hot reload |
| Routing | React Router | Client-side navigation |
| State | Context API | Auth and Theme management |
| Backend | Express.js | REST API server |
| Storage | File System (JSON) | Books, Drawings, Public shares |
| Deploy | GitHub Actions + PM2 | CI/CD to Azure Web App |

## API Endpoints

### Authentication
| Method | Endpoint | Description |
|--------|----------|-------------|
| POST | /api/login | User login |
| POST | /api/register | User registration |
| GET | /api/me | Get current user |

### Books (Markdown Files)
| Method | Endpoint | Description |
|--------|----------|-------------|
| GET | /api/books | List all books |
| POST | /api/books | Create new book |
| PUT | /api/books/:id | Update book content |
| DELETE | /api/books/:id | Delete a book |

### Public Sharing
| Method | Endpoint | Description |
|--------|----------|-------------|
| POST | /api/public/share | Share markdown publicly |
| GET | /api/public/:shareId | Get shared content |
| DELETE | /api/public/:shareId | Remove shared content |

### Drawings (Excalidraw)
| Method | Endpoint | Description |
|--------|----------|-------------|
| POST | /api/draw | Create new drawing |
| GET | /api/draw/list | List all drawings |
| GET | /api/draw/:drawId | Get drawing data |
| PUT | /api/draw/:drawId | Update drawing |
| DELETE | /api/draw/:drawId | Delete drawing |

## Getting Started

    # Install dependencies
    npm install

    # Start development (frontend + backend)
    npm run dev

    # Build for production
    npm run build

    # Start production server
    npm start
