# Markdown Live Preview - Technical Documentation

## Overview

**Markdown Live Preview** is a full-stack web application for real-time markdown editing, previewing, and sharing. Built with React + Vite (frontend) and Express.js (backend).

## Tech Stack

| Layer | Technology | Purpose |
|-------|-----------|---------|
| Frontend | React 18 + Vite | SPA with hot reload |
| Routing | React Router | Client-side navigation |
| State | Context API | Auth & Theme management |
| Backend | Express.js | REST API server |
| Storage | File System (JSON) | Books, Drawings, Public shares |
| Deploy | GitHub Actions + PM2 | CI/CD to Azure Web App |

## API Endpoints

### Authentication
| Method | Endpoint | Description |
|--------|----------|-------------|
| POST |  | User login |
| POST |  | User registration |
| GET |  | Get current user |

### Books (Markdown Files)
| Method | Endpoint | Description |
|--------|----------|-------------|
| GET |  | List all books |
| POST |  | Create new book |
| PUT |  | Update book content |
| DELETE |  | Delete a book |

### Public Sharing
| Method | Endpoint | Description |
|--------|----------|-------------|
| POST |  | Share markdown publicly |
| GET |  | Get shared content |
| DELETE |  | Remove shared content |

### Drawings (Excalidraw)
| Method | Endpoint | Description |
|--------|----------|-------------|
| POST |  | Create new drawing |
| GET |  | List all drawings |
| GET |  | Get drawing data |
| PUT |  | Update drawing |
| DELETE |  | Delete drawing |
