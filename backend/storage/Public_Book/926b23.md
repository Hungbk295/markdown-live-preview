## Key Components

### 1. Skill Manager (`skill-manager.ts`)
```typescript
interface Skill {
  id: string;           // folder name
  name: string;         // from frontmatter
  description: string;  // from frontmatter
  path: string;         // absolute path
  content: string;      // full SKILL.md content
  references: string[]; // list of reference files
  embedding?: number[]; // cached embedding vector
}

class SkillManager {
  scanSkillsDirectory(): Promise<Skill[]>
  getSkill(id: string): Promise<Skill>
  getSkillContent(id: string, includeReferences: boolean): Promise<string>
  watchForChanges(): void  // fs.watch
}
```

### 2. Embedding Service (`embedding-service.ts`)
```typescript
class EmbeddingService {
  private provider: 'openai' | 'claude';

  async embed(text: string): Promise<number[]>
  async embedBatch(texts: string[]): Promise<number[][]>

  // OpenAI: text-embedding-3-small (1536 dims)
```

## Data Flow

```
[User clicks profile]
    → ProfileManager.getProfile()
    → SkillManager.getSkillContent() for each skill
    → TerminalService.launchClaude()
        → spawn node-pty
        → run "claude --dangerously-skip-permissions"
        → inject formatted skills
    → xterm.js displays terminal
```
