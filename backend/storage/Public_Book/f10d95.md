# Kiến Trúc Cơ Chế Heartbeat của OpenClaw

Dựa trên phân tích codebase, đây là kiến trúc heartbeat của openclaw.

---

## 1. Các File Chính

| File | Chức năng |
|------|-----------|
| `src/infra/heartbeat-runner.ts` | Orchestrator chính - scheduling & execution |
| `src/infra/heartbeat-wake.ts` | Cơ chế wake với coalescing |
| `src/infra/heartbeat-events.ts` | Phát sự kiện lifecycle |
| `src/infra/heartbeat-visibility.ts` | Cấu hình hiển thị messages |

## 2. Luồng Hoạt Động

```
┌─────────────────────────────────────────────────────────────────┐
│                     GATEWAY STARTUP                              │
└─────────────────────┬───────────────────────────────────────────┘
                      ▼
┌─────────────────────────────────────────────────────────────────┐
│  startHeartbeatRunner({ cfg })                                   │
│  → loadConfig()                                                  │
│  → resolveHeartbeatAgents()                                      │
│  → Tạo HeartbeatAgentState[] cho mỗi agent                       │
└─────────────────────┬───────────────────────────────────────────┘
                      ▼
┌─────────────────────────────────────────────────────────────────┐
│  scheduleNext()                                                  │
│  → Tính nextDueMs = now + intervalMs                             │
│  → setTimeout(requestHeartbeatNow, delay).unref()                │
└─────────────────────┬───────────────────────────────────────────┘
                      │
     ┌────────────────┼────────────────┐
     │                │                │
  [Timer]      [Manual Wake]    [Exec Event]
     │                │                │
     └────────────────┼────────────────┘
                      ▼
┌─────────────────────────────────────────────────────────────────┐
│  requestHeartbeatNow({ reason, coalesceMs })                     │
│  → Coalescing 250ms (gộp nhiều request)                          │
└─────────────────────┬───────────────────────────────────────────┘
                      ▼
┌─────────────────────────────────────────────────────────────────┐
│  runHeartbeatOnce()                                              │
│  ├─ Check: enabled? configured? quiet-hours? queue-empty?        │
│  ├─ Load: session, delivery target, visibility                   │
│  ├─ Run: agent với heartbeat prompt                              │
│  ├─ Parse: response, strip HEARTBEAT_OK                          │
│  ├─ Deliver: gửi qua channel plugin                              │
│  └─ Emit: heartbeat event → Broadcast WebSocket                  │
└─────────────────────┬───────────────────────────────────────────┘
                      ▼
               scheduleNext() [lặp lại]
```

## 3. State Management

```typescript
type HeartbeatAgentState = {
  agentId: string;
  heartbeat?: HeartbeatConfig;
  intervalMs: number;        // Khoảng cách giữa các heartbeat
  lastRunMs?: number;        // Thời điểm chạy lần cuối
  nextDueMs: number;         // Thời điểm chạy tiếp theo
};
```

---

## 4. Cấu Hình Mặc Định

| Config | Giá trị | Mô tả |
|--------|---------|-------|
| `heartbeat.every` | "30m" (API key) / "1h" (OAuth) | Interval |
| `heartbeat.ackMaxChars` | 300 | Max chars cho ack message |
| `heartbeat.target` | "last" | Kênh gửi (last channel used) |
| `heartbeat.filename` | "HEARTBEAT.md" | File chứa prompt |
| `activeHours.start` | "08:00" | Giờ bắt đầu |
| `activeHours.end` | "24:00" | Giờ kết thúc |

---

## 5. Skip Conditions (theo thứ tự)

1. **Disabled** - heartbeatsEnabled = false
2. **Not configured** - không có interval
3. **Quiet hours** - ngoài activeHours
4. **Queue busy** - có request đang pending
5. **Empty file** - HEARTBEAT.md trống
6. **No target** - không có kênh delivery
7. **Visibility disabled** - tất cả flag đều false

---

## 6. Response Contract

| Agent Reply | Action |
|-------------|--------|
| `"HEARTBEAT_OK"` (chỉ có token) | Skip delivery (trừ showOk=true) |
| `"HEARTBEAT_OK"` + text ≤ 300 chars | Strip token, skip delivery |
| `"HEARTBEAT_OK"` ở giữa text | Giữ nguyên, delivery bình thường |
| Text không có token | Delivery bình thường |

---

## 7. Event Broadcasting

```typescript
HeartbeatEventPayload = {
  status: "sent" | "ok-empty" | "ok-token" | "skipped" | "failed",
  to: string,              // Recipient
  channel: string,         // whatsapp, telegram, discord...
  preview: string,         // First 200 chars
  durationMs: number,
  reason?: string,         // Skip reason
  indicatorType: "ok" | "alert" | "error"
}
```

**Flow:** `runHeartbeatOnce()` → `emitHeartbeatEvent()` → `onHeartbeatEvent` → `broadcast()` → WebSocket clients

---

## 8. Multi-Agent Support

- Mỗi agent có thể có config heartbeat riêng
- Override: `agents.list[id].heartbeat` > `agents.defaults.heartbeat` > default
- Tất cả agents được track độc lập nhưng schedule bằng 1 timer duy nhất (coalesced)

---

## 9. Điểm Đặc Biệt

| Feature | Mô tả |
|---------|-------|
| **Coalescing** | Gộp nhiều wake request trong 250ms để tránh spam |
| **Unref()** | Timer không block process exit |
| **Timezone-aware** | ActiveHours hỗ trợ timezone khác nhau |
| **Channel readiness** | Plugin có thể implement `heartbeat.checkReady()` |
| **Duplicate detection** | Không gửi message trùng trong 24h |
